This spec stresses argument-boundary detection for the operator-to-macro
 rewrite: deeply nested calls, calls spanning multiple lines, and arguments
 that
 contain function application brackets, tuples, and records. A correct parser
 must track paren/bracket/brace depth to find each argument\mbox{'}s true
 extent.
\end{cpar}%
\end{lcom}%
