 This spec enumerates the different operator \ensuremath{\.{*}fixities\.{*}}
 and shapes \ensuremath{TLATeX} must
 recognize when deciding what can be rewritten into a \ensuremath{TeX} macro:
 prefix, infix,
 postfix, higher-order (operator-valued) parameters, and user-defined symbolic
 operators. It is a map of the parsing surface, not a semantic model.
\end{cpar}%
